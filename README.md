# Falcon2RU

## Requirements

- Git any
- GCC 13 >
- CMake 3.28 >
- GNU Make 4 >

## Build

```bash
git clone https://git.sr.ht/~mkoushan/Falcon2RU
cd Falcon2RU
mkdir build/
cmake -S . -B build/
cd build/
make -j # -j for speeding things up

# Falcon2RU test-benches (Optional)
git submodule update --init --recursive
```
